# 🧩 Лабораторная работа №1   
### Проект: SmartCity System

---

## 📘 Описание задания

SmartCity System представляет собой консольное приложение, моделирующее работу интеллектуальной системы управления элементами умного города.  
Система объединяет различные подсистемы, отвечающие за освещение, транспорт, безопасность, энергосбережение, мониторинг и другие функции городской инфраструктуры.

Каждая подсистема реализуется с использованием паттернов проектирования, обеспечивающих архитектурную устойчивость и расширяемость проекта.

---

## 🧱 Основные требования

1. Проект реализуется на языке **Любом** с применением **объектно-ориентированного подхода**.  
2. В архитектуре должно быть применено **не менее пяти паттернов проектирования** из представленного перечня.  
3. Каждый паттерн должен иметь функциональное назначение в системе.  
4. Система должна быть логически целостной и состоять из взаимосвязанных компонентов.  
5. Взаимодействие с пользователем осуществляется через консольный интерфейс.  
6. Для каждого паттерна в коде указывается комментарий или docstring с пояснением его использования.

## ⚙️ Структура проекта

Проект организуется в виде модульного приложения.  
Рекомендуемая структура директорий:

smartcity/
├── main.py                     # Основной запуск приложения
├── core/                       # Основные компоненты системы
│   ├── controller.py           # Центральный контроллер / Facade / Singleton
│   ├── factories/              # Порождающие паттерны (Factory, Abstract Factory)
│   ├── builders/               # Builder для пошаговой сборки объектов
│   ├── adapters/               # Adapter для интеграции внешних сервисов
│   ├── proxy/                  # Proxy для контроля доступа к подсистемам
│   └── singleton/              # Singleton для уникальных компонентов
├── modules/                    # Подсистемы умного города
│   ├── transport/              # Управление транспортом
│   ├── lighting/               # Управление освещением
│   ├── security/               # Подсистема безопасности
│   └── energy/                 # Энергосбережение и мониторинг
└── README.md                   # Описание задания и структуры проекта
