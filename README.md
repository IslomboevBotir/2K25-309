# 🏙️ SmartCity Management System

**Laboratory Work №1** - Design Patterns Implementation

## 📖 Project Description

SmartCity System is an intelligent city management console application that simulates urban infrastructure control. The system integrates multiple subsystems including transportation, lighting, security, and energy monitoring using object-oriented design patterns.

## 🧩 Design Patterns Implemented (5/5)

| Pattern | Type | Location | Purpose |
|---------|------|----------|---------|
| **Singleton** | Creational | `core/controller.py` | Ensures single instance of city controller |
| **Factory Method** | Creational | `core/factories/` | Creates vehicles and lights dynamically |
| **Builder** | Creational | `core/builders/` | Constructs complex city configurations |
| **Adapter** | Structural | `core/adapters/` | Integrates external sensors with unified interface |
| **Facade** | Structural | `core/controller.py` | Simplifies interaction with subsystems |
